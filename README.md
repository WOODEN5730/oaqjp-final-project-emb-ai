# Repository for Final project
Project Description

The Emotion Detection Application is a Python-based application that analyzes text and identifies the emotions expressed by the user.

The application uses the IBM Watson Emotion Detection API to identify five emotions:

Anger
Disgust
Fear
Joy
Sadness
It also determines the dominant emotion in the submitted text.

Technologies Used

Python 3
Flask
Requests library
IBM Watson Emotion Detection API
JSON
Git and GitHub
